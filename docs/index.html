Git worktrees without the setup friction

git worktree add is fast. Everything after — .env files, node_modules, install scripts — is where you give up. Grove automates all of that.

Install View on GitHub 
$ grove create feature/auth
Creating worktree for branch "feature/auth" at /home/dev/myapp-auth
  ✓ git worktree created
  ✓ copied 2 .env file(s)
  ✓ symlinked node_modules
  ✓ afterCreate done

Worktree "auth" ready (port 3487).
  cd $(grove cd auth)

What it does

Auto .env copy

Walks the project recursively and copies every .env* file to the new worktree, preserving directory structure.

node_modules symlinks

Instead of reinstalling per worktree, Grove symlinks configured directories from the main tree. Detach when branches diverge.

Build cache (copyDirs)

Copy .next, dist, target into new worktrees for a warm start.

Per-worktree ports

Every worktree gets a stable port via alias hash. Exposed as $GROVE_PORT in your setup script.

PR review

grove review 42 checks out a GitHub pull request into a ready-to-run worktree via gh CLI.

afterCreate hooks

Run one command or an array of commands after setup. Fail-fast, with $GROVE_ALIAS/BRANCH/PORT/PATH in scope.

Orphan handling

grove adopt registers worktrees created outside of Grove. grove doctor finds stale state and broken symlinks.

Templates

Save any .groverc.json as a reusable template. grove init --template nextjs in a new project.

Interactive picker

grove cd with no args opens a fuzzy picker. Tab completion for aliases in every command.

Install

Homebrew (macOS & Linux)

$ brew tap verbaux/tap
$ brew install grove

Go install

$ go install github.com/verbaux/grove@latest

Binary releases

Prebuilt binaries for darwin & linux, amd64 & arm64 on the Releases page.

Commands

grove initInteractive wizard — creates .groverc.json
grove create <branch>Create worktree + copy envs + symlinks + afterCreate
grove listTable of worktrees with status, port, and index
grove cd [name|index]Print path to cd into; interactive picker without args
grove remove <name>Remove a worktree (dirty-state check)
grove cleanRemove all managed worktrees + orphan cleanup
grove adoptRegister an orphan worktree
grove review [pr]Check out a GitHub PR into a worktree
grove detachRemove symlinks (optionally copy contents first)
grove doctorDiagnose config, state, symlinks, ports, dependencies
grove templateSave / list / apply reusable configs
grove completionShell completion for zsh, bash, fish, powershell

01 · the problem

The part nobody ships.

Worktrees are almost perfect for parallel branches. Almost.

plain git worktree add
  • ✕.env files missing
  • ✕no node_modules, full reinstall
  • ✕cold build cache
  • ✕port 3000 collision
  • ✕setup script not run
  • ✕orphans when you forget
with grove create
  • ✓.env* copied recursively
  • ✓node_modules symlinked
  • ✓.next / dist warm-copied
  • ✓stable port from alias hash
  • ✓afterCreate hook runs
  • ✓state locked + atomic in .grove/state.json
02 · features

Everything git worktree add should've done.

Seventeen small behaviors, grouped by when they matter.

myapp/
├── main/          ● clean
├── auth/          ● clean
│   └── node_modules →
├── payments/      ● dirty
│   └── node_modules →
└── review-42/     ● clean
    └── node_modules →

Symlinked node_modules

No reinstall per worktree. Root-relative globs like apps/*/node_modules keep every workspace linked. grove detach breaks the links when branches diverge.

Auto .env copy

Walks the project recursively and copies every .env*, preserving directory structure.

Build cache

Copy .next, dist, or packages/*/dist for a warm start. copyDirsOnDetach: false keeps detached branches clean.

afterCreate hooks

One command or an array. Fail-fast, with $GROVE_ALIAS/BRANCH/PORT/PATH in scope.

Project detection

grove analyze spots package managers, Docker Compose, Vite, Next.js, Turbo, Go, Python, Ruby, Cargo, Gradle — and proposes config.

Templates

Save any .groverc.json as a template. grove init --template nextjs in the next project.

main:3000
auth:3487
payments:3612
pr-42:3721

Per-worktree ports

Every worktree gets a stable port hashed from its alias — same alias, same port, every time. Exposed as $GROVE_PORT in your setup script.

PR review

grove review 42 checks out a GitHub PR into a ready-to-run worktree via gh.

Interactive picker

grove cd with no args opens a fuzzy picker. Tab completion everywhere.

Worktree notes

grove note auth "waiting for review" keeps short context beside the worktree, shown in list and status.

Daily status

grove status: dirty trees, config drift, broken symlinks, port collisions, orphans, branch freshness. Read-only.

Config sync

Changed .groverc.json? grove sync adds missing symlinks, envs and copyDirs to existing worktrees.

Protected worktrees

grove protect keeps a worktree out of remove, clean and prune until you opt in.

Merged-branch cleanup

grove prune removes worktrees whose branches are merged — squash-merged PRs included.

Orphan handling

grove adopt registers outside worktrees. grove doctor --fix repairs only unambiguous issues.

Detached worktrees

grove create --detach skips symlinks and runs afterDetachedCreate. sync --reattach reverses it.

Agent skill

Ships an embedded skill. grove skill install detects Claude and Codex-style skill dirs, so agents route worktree ops through Grove. See it in action ↓

03 · agents

Parallel agents, parallel worktrees.

Hand each agent its own branch. Grove gives it a working copy that actually boots, on its own port.

  1. Install the skillgrove skill install finds Claude / Codex-style skill dirs.
  2. Agents create worktreesInstead of raw git worktree, they call grove create, so envs and deps are always there.
  3. Run without cdgrove exec <name> -- <cmd> runs tests in place, with GROVE_PORT set and exit codes passed through.
agent session~/myapp
Fix the sidebar overflow in parallel — don't touch my auth branch.
I'll work in a separate worktree.
$ grove create fix/sidebar --name sidebar ✓ envs · symlinks · afterCreate → port 3804
$ grove exec sidebar -- npm test ✓ 214 passed
Fixed and tested in sidebar on :3804. Your auth worktree is untouched.

05 · reference

Commands.

Grouped by when you'd reach for them.

01

Setuponce per project

6 commands+
  • grove initInteractive wizard — creates .groverc.json, offers detected conventions
  • grove analyzeSuggest config additions; --apply --clean --dry-run --json
  • grove templateSave / list / show / apply / delete reusable configs
  • grove skillInstall, uninstall, or inspect the embedded agent skill
  • grove shell-initCompletion + a gcd helper to eval from your shell rc
  • grove completionzsh, bash, fish, powershell
02

Dailythe ones you'll alias

10 commands+
  • grove create <branch>Create worktree + setup; --name --from --detach
  • grove cd [name|index]Print path to cd into; fuzzy picker without args
  • grove open [name|index]Open in your editor; editor config / $EDITOR / --editor
  • grove exec <name> -- <cmd>Run a command in a worktree with GROVE_PORT set
  • grove listStatus, detached mode, port, note, index; --json --plain
  • grove statusRead-only health: dirty state, drift, symlinks, ports, orphans, freshness
  • grove psLive running/stopped status for assigned ports
  • grove review [pr]List open PRs or check one out; --name sets the alias
  • grove rename <name> <alias>Rename a worktree; preserves its port
  • grove note <name> [text]Show or set a short note; --clear removes it
03

Maintenancewhen things get messy

8 commands+
  • grove remove <name>Remove safely; --force --delete-branch --include-protected
  • grove cleanRemove managed worktrees + orphans; protected ones skipped
  • grove pruneRemove merged worktrees; --base --dry-run --yes
  • grove sync <name>Apply current config to a worktree; --hooks --reattach
  • grove protect <name>Keep out of remove/clean/prune; grove unprotect reverses
  • grove adoptRegister an orphan worktree
  • grove detachRemove symlinks; --copy preserves contents first
  • grove doctorDiagnose config, state, symlinks, ports, deps; --fix
